# Styling Fundamentals

A foundational HTML & CSS project focused on applying different types of styling: external stylesheets, embedded styles, and inline styles. The goal was to practice working with style layers, text formatting, colors, and basic CSS selectors for a visually organized page.

## Live Demo
[Click here to view](https://yevgen2022.github.io/Ed-intro-css-basics/)

## Key Concepts Applied

- Added external and internal CSS styles properly using `<link>` and `<style>` in `<head>` and `<body>`
- Used inline style to style a specific element directly via the `style` attribute
- Applied base typography styles globally: font families, sizes, text transformation
- Used element, class, and ID selectors for targeting
- Styled links with different states: default, visited, and hover
- Applied list style customization using `list-style-type: upper-roman`
- Practiced using border, padding, and radius for layout and visual polish
